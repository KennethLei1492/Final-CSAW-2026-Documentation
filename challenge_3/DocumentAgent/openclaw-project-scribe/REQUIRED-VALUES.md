# Values to fill before installation

Keep secrets on your machine. The installer does not need them in chat.

| Value | Where it goes | Required? | Example / how to find it |
|---|---|---|---|
| Deployment environment | Your installation choice | Yes | One local Windows, WSL2, Linux, or macOS host; coding CLIs and Gateway use that environment |
| Permanent package path | Location where ZIP is extracted | Yes | `/home/you/tools/openclaw-project-scribe` or `C:/Tools/openclaw-project-scribe` |
| Project name | `project.name` | Yes | `CSAW Challenge 3` |
| Project/worktree roots | `project.roots` | Yes | Run `git rev-parse --show-toplevel` in each checkout; add every participating worktree explicitly |
| Event database directory | `stateDir` | Yes | `/home/you/.local/state/project-scribe`; script creates `events.db` inside |
| Local reports directory | `outputDir` | Yes | `/home/you/project-docs` |
| Dedicated OpenClaw workspace | `workspaceDir` | Yes | `/home/you/.openclaw/workspace-project-scribe` |
| Node and OpenClaw executable path(s) | `openclaw.command` | Yes | `["/absolute/openclaw"]`; on native Windows, use `node.exe` plus the actual OpenClaw `.mjs` entry |
| OpenClaw agent ID | `openclaw.agentId` | Default provided | `project-scribe`; use a unique ID if already taken |
| Synthesis model identifier | `openclaw.model` | Yes for synthesis | Pick the exact `provider/model` from your configured `openclaw models list` |
| Model provider credentials/login | OpenClaw onboarding/provider config | Yes for synthesis | Existing compatible OpenClaw auth; no model API key belongs in `config.json` or workspace Markdown |
| Claude hook settings file | `hooks --provider claude --target ...` | For Claude capture | `~/.claude/settings.json` or each root's `.claude/settings.local.json` |
| Codex hook settings file | `hooks --provider codex --target ...` | For Codex capture | `~/.codex/hooks.json`, custom `CODEX_HOME/hooks.json`, or each root's `.codex/hooks.json`; review with `/hooks` |
| Google Cloud project | Google Cloud console | For publishing | Any project you control with the Google Docs API enabled; project ID is not consumed by this script |
| Destination document ID | `google.documentId` | For publishing | The `ID` in `https://docs.google.com/document/d/ID/edit` |
| Destination tab ID | `google.tabId` | For publishing | Run `google-inspect` after setting document ID/auth; select a blank tab or add managed markers |
| Authentication mode | `google.authMode` | For publishing | `oauth` or `service_account` |
| OAuth Desktop client JSON path | `google.oauthClientFile` | OAuth only | Download the Desktop app client config; keep it outside observed repositories |
| Refresh-token output path | `google.tokenFile` | OAuth only | Private writable absolute filename, generated by `google-auth` |
| Authorized Google account | Browser OAuth login | OAuth only | An account that can edit the destination Doc; add as test user when needed |
| Service-account JSON key path | `google.serviceAccountFile` | Service account only | Private absolute path; never commit the JSON |
| Service-account editor access | Google Doc sharing | Service account only | Share the Doc to the JSON's `client_email` as Editor |
| Refresh interval | `schedule.every` | Default provided | `15m`; examples `30m`, `1h` |
| Source documents/modules | `git.sourceFiles` | Optional, useful | Array of `{ "root": 0, "path": "README.md" }`; paths are relative to the chosen root |
| Patch inclusion | `git.includePatches` | Optional | Default `false`; enabling sends redacted patch excerpts to the model and Google report |
| Assistant message inclusion | `capture.assistantMessages` | Default provided | `true`; turn off if only metadata should be collected |
| Tool output inclusion | `capture.toolResults` | Optional | Default `false`; explicit test-wrapper output is always a bounded, redacted excerpt |
| Additional secret patterns | `capture.redactPatterns` | Optional | JavaScript regular-expression strings, with JSON escaping |

Not required: Claude or Codex transcript/session directory paths, a Drive folder ID, a Google API key, a webhook URL, an OpenClaw channel ID, or a GitHub access token. Git observation is local. Historical log ingestion and cross-machine collection are not included.

The package can be installed and previewed without Google credentials. Synthesis needs working OpenClaw model authentication. Publishing additionally needs Google credentials and edit access. Scheduling additionally needs a running Gateway with administrator authority. Fill only the credential paths for the authentication mode you choose; unused placeholders are ignored.
